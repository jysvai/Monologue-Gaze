# Codex 에 줄 지시문

## SVG → 이미지 30장 (docs/IMAGE_SVG.md)

아래 블록을 그대로 붙여 넣는다.

```
docs/IMAGE_SVG.md 를 열고, 표에 「⬜ 뽑을 것」으로 적힌 그림 30장을 차례로 만들어 줘.

- 각 항목의 코드 블록이 완성 프롬프트다. 그대로 쓰고, 표에 적힌 비율을 지켜.
- 저장: img/<사건>/<키>.png (예: img/c01/map.png). 파일 이름은 표와 똑같이.
- 글자 금지: 지명·번호·간판·쪽지 글씨를 넣지 마. 지도는 글자 없는 그림만 (지명은 게임이 얹는다). 또렷한 가짜 글자가 나오면 다시 뽑아.
- 「꼭 보여야 할 것」이 가장 중요하다. 특히 단서 물건의 자리(왼쪽 위·오른쪽 아래 등)를 지켜. 게임이 그 자리를 눌러서 단서를 찾게 한다.
- 대조 시료(c05 봉투 5장, c11 톱 자국 5장)는 서로 다른 점이 정답을 가른다: 우표가 거꾸로인지, 편지 접힌 자국 수, 주소가 볼펜·타자·연필인지, 줄무늬 간격과 휜 정도. 한 장 만들 때마다 꼭 확인해.
- c11 톱 자국은 회색 실리콘 본(자국을 뜬 것) 사진이다. 뼈나 살, 피는 넣지 마.
- 한 장마다 스스로 검사하고, 단서가 빠졌으면 한 번 다시 만들어. 그래도 완벽하지 않으면 가장 나은 것을 저장하고 넘어가 (건너뛰지 마).
- 다른 파일은 고치지 말고 git 도 건드리지 마.
- 끝나면 저장한 파일 목록과, 아쉬운 점이 남은 그림을 짧게 정리해 줘.
```

그림이 들어오면 `node tools/optimize-images.js` 로 변환한 뒤, 관찰 사진의 단서 좌표와 지도의 지명 자리를 그림에 맞춰 옮긴다.

# 다시 뽑을 이미지

> `node tools/prompts.js` 가 자동으로 만든다. 사건 파일 `art` 항목의 `redo` 표시를 모은 것이다.

총 **0장** (필수 0 · 강화 0 · 선택 0). 같은 경로·같은 이름으로 넣으면 게임 그림이 자동으로 바뀐다. 바꾼 뒤에는 그 항목의 `redo` 표시를 지운다.

- **필수**: 이야기·단서와 어긋나 꼭 다시 뽑아야 한다. **강화**: 빨간 별 사건의 수위를 올린 그림 (기존 교체 + 새 그림). **선택**: 지금도 쓸 만하지만 더 나아질 수 있다.

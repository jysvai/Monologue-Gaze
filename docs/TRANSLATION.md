# 번역 (다른 언어)

게임의 원문은 한국어다. 영어·일본어·중국어(간체)·러시아어·독일어 번역은 원문 위에 덮인다.
기록실 위쪽의 언어 칸에서 고르면 페이지를 새로 불러온다. 처음 여는 사람은 브라우저 언어로 정해지고, 없는 언어면 영어로 연다.
주소 끝에 `?lang=en` 을 붙여도 그 언어로 열린다.

## 파일

```
js/i18n.js              언어 고르기 · 화면 글자 T · 번역 덮기 · 날짜 꼴 · 언어별 글꼴 부르기
css/i18n.css            언어별 글꼴 (html[lang] 마다 --l-… 변수. css/base.css 의 글꼴 변수 앞자리에 들어간다)
i18n/<언어>/ui.js       화면 글자: 한국어 → 번역
i18n/<언어>/finale.js   서랍 맨 밑의 편지 (js/finale.js)
i18n/<언어>/cNN.js      사건 기록: 한국어 글 한 토막의 지문 → 번역
tools/i18n.js           원문 뽑기 · 번역 넣기 · 검사
```

`i18n/` 의 파일은 모두 `node tools/i18n.js put` 이 만든다. 손으로 고치지 않는다.

## 어떻게 덮이나

- **화면 글자**는 코드에 `` T`한국어 ${x}` `` 나 `T('한국어')` 로 적는다. 번역 꾸러미의 열쇠는 그 한국어이고, 자리 표시는 `{0}` `{1}` … 로 바뀐다.
  번역이 없으면 한국어가 그대로 나온다. 조사가 붙는 자리는 `` T`${L}${josa(L, '과', '와')} …` `` 처럼 조사만 따로 둔다 (다른 언어에서는 빈칸).
- **사건 기록**은 한글이 든 문자열마다 원문의 지문(53비트 해시)을 열쇠로 둔다. 원문을 한 글자라도 고치면 그 토막의 지문이 바뀌어 번역이 떨어지고,
  그 자리만 한국어로 나온다. 게임은 멈추지 않는다. `node tools/i18n.js check` 가 빠진 곳을 센다.
- 그림을 만드는 데만 쓰는 칸(`svg` `prompt` `must` `avoid` `redo` `artStyle` `css` `initial`)은 번역하지 않는다.
- **답으로 치는 값**(잠금 `code`, 조회 `match` 의 값, 편지의 `answer`, 단어의 `alias`)은 통째로 한 토막이고 번역은 배열이다.
  게임은 한국어 값과 번역 값을 합쳐서 받는다 — 어느 언어로 쳐도 맞는다. 단어의 한국어 이름도 별칭으로 남는다.
- 번역문의 단어 고리는 `[[번역된 이름|k_id]]` 로 id 를 꼭 적는다. 원문이 `[[이름]]` 만 적었어도 `tools/i18n.js src` 가 id 를 붙여 보여 준다.
- 세로쓰기 신문(`cls: 'vertical'`)은 일본어·중국어에서만 세로로 나오고, 다른 언어에서는 가로로 바뀐다.
- 날짜·시각(현행 사건의 시계, 단톡방 날짜 줄, 결말의 `{{t}}` `{{d}}`)은 그 언어의 꼴로 나온다.
- 한글이 없어 번역 꾸러미에 들지 않는 칸 가운데 칸 전체가 날짜인 것(`10.09 20:31` · `1922.10.14` · `① 11/5 07:40` · `6.20 ~`)은
  엔진이 독일어·러시아어에서 일.월 순서로, 영어에서 달 이름으로 바꿔 보여 준다 (`js/i18n.js` 의 `localDates`). 일본어·중국어는 원문 그대로.
- 목소리 파일은 한국어 그대로 나오고, 주인공 속말 자막만 번역된다.

## 번역하기

```bash
node tools/i18n.js src c03 dist/i18n-work/c03.json      # 원문 토막 목록 (ui · finale · c00 … c15)
#   → { "<지문>": "<번역>" } JSON 을 만든다 (ui 는 { "<한국어>": "<번역>" })
node tools/i18n.js put en c03 dist/i18n-work/en/c03.1.json   # 검사를 통과한 것만 i18n/en/c03.js 에 넣는다
node tools/i18n.js check                                 # 언어 × 부분마다 채운 수 · 빠짐 · 낡음 · 어긋남
node tools/i18n.js check en c03 -v                       # 빠진 토막과 어긋난 곳을 하나씩
```

`put` 이 거르는 것: 걸린 단어 id 가 원문과 다름, 없는 단어 id, `**굵게**` · `~~줄~~` · `{{t}}` · `{n}` 개수가 다름, 화면 글자의 태그·자리 표시가 다름, 답 값이 빈 배열,
원문 글에 적힌 **번역되지 않는 답**(한글이 없는 조회 값·잠금 번호, 예: CASE 11 도장 `11.07-③`)이 번역문에서 모양이 바뀜 — 게임은 그 모양만 받는다.
경고만 하는 것: 대사 앞 몸짓 `(…)` 이나 끼어든 말 `— ` 이 원문과 다름, 한글이 남음.

번역의 결은 원문을 따른다. 서류는 서류답게 짧게, 신문은 그 시대 신문처럼, 대화는 그 사람의 말투 그대로.
원문에 없는 설명·꾸밈을 보태지 않는다. 사람 이름은 영어·독일어는 개정 로마자 표기(Han Seo-yun), 일본어는 가타카나, 중국어는 한자, 러시아어는 콘체비치 표기.
외국이 무대인 사건은 한글로 옮겨 적힌 이름을 본래 철자로 되돌린다. 숫자·날짜·시각·주소 번호·번호판은 꼴만 바꾸고 값은 그대로 둔다 — 단서가 서로 맞물린다.
날짜는 그 언어의 순서로 적는다: 독일어 `3.2.` · 러시아어 `03.02` (일.월), 영어 `Feb 3` (달 이름), 일본어·중국어는 원문처럼 월.일.
검색 단어가 날짜면(`k_mar17` 같은) 그 언어로 적힌 모양을 별칭에도 넣는다.

## 사건을 새로 쓰거나 고칠 때

- 원문을 고치면 그 토막의 번역은 다섯 언어 모두 떨어진다. 고친 뒤 `node tools/i18n.js check` 로 몇 곳이 빠졌는지 보고 채운다.
- 그림 안에는 글자를 그리지 않는다. 지도·도표에 글자가 필요하면 `labels` 로 얹는다 (번역된다). 도표의 눈금 글자처럼 테두리 없이 얹으려면 `labelStyle: 'axis'` 와 다섯째 값(글자 크기, 그림 너비의 %)을 쓴다 (CASE 08 성문).
- 새 화면 글자를 엔진에 넣을 때는 `T` 로 감싼다. 감싸지 않은 한글은 모든 언어에서 한국어로 나온다.
- CSS 의 `content:` 글자는 `var(--t-이름,"한국어")` 로 적고, `js/i18n.js` 의 `cssText()` 에 한 줄 더한다.

## 남은 한계

- 언어를 바꾸기 전에 수첩에 적은 메모는 적을 때의 언어로 남는다.
- 일부 사진 속의 손글씨·간판은 알아볼 수 없는 흘림 글씨라 그대로 둔다 (단서는 모두 글에 있다).
